STRANGER-INSPIRED CINEMATIC NAME INTRO

1. Extract the ZIP file.
2. Keep the assets folder beside index.html.
3. Open index.html in Chrome, Edge, or Firefox.
4. Enter a name and press BEGIN THE INTRO. The bundled soundtrack starts after this click because browsers block autoplay before user interaction.
5. Use REPLACE AUDIO if you want to choose a different soundtrack from your device.

The included soundtrack is user-provided and is intended only for private testing where you have the necessary rights. Do not publish or distribute the audio publicly without permission/licensing from the rights holder.

For best results, keep an internet connection available for the display font. The page itself is responsive and runs locally.
